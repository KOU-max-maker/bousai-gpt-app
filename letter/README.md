# 綴 -Tsuzuru- | 想いが動き出す、電子手紙

遠く離れた大切な人へ贈る「動く手紙」を作成・共有できる、自己完結型アプリです(`index.html` と、世界地図用の衛星写真画像 `world.jpg` の2ファイル構成)。

受け取った人がリンクを開くと──

1. 世界地図の上を、差出人の国から届け先の国へ手紙が飛んでいく(設定でオフにできます)
2. お家の郵便ポストに、手紙がすとんと届く
3. 静かな情景の中に、封蝋の押された封筒が届く
4. 封蝋にふれると封が開き、便箋が封筒からすべり出て広がる
5. 万年筆が現れ、読むほどの速さで一文字ずつ、インクが染みるように文章を綴っていく
6. 署名まで書き終えると、ペンが静かに離れる

## 書き手が設定できるもの

| 項目 | 内容 |
|---|---|
| 便箋 | クラシック・クリーム / ピュア・ホワイト / 和紙 / ミッドナイト / ローズ の5種(情景・封筒も連動) |
| 書き方向 | 横書き / 縦書き |
| 筆致(フォント) | クレー(万年筆) / 紅道(細字ペン) / よもぎ / 佑字肅(毛筆) / しっぽり明朝 |
| 文字サイズ | 小 / 中 / 大 |
| インク | ブルーブラック / 漆黒 / セピア / ボルドー / 深緑 / ゴールド |
| 綴るはやさ | 5段階(句読点・改行で自然な間を取る) |
| 文字の書き方 | にじみ(ふわりと浮かぶ) / 一筆ずつ(画をかさねる) / ながれ(線を引くように) |
| 筆記音 | 万年筆 / 鉛筆 / 筆 / タイプライター / なし(Web Audio でリアルタイム合成) |
| 封蝋 | 色4種 |
| BGM | YouTubeのURL(公式埋め込みプレイヤーを画面外で再生)、または mp3 等への直リンク。開封と同時にフェードイン |
| 手紙の旅 | 出発地・届け先の国(約50か国)を選ぶと、封筒が届く前に衛星写真ふうの世界地図の上を弧を描いて手紙が飛び、お家のポストに投函されるまでのアニメーションが流れます。選んだ2都市に合わせてズーム(見せる/見せないを切替可能) |
| その他 | 宛名・差出人・日付の有無 |

## 仕組みとプライバシー

- 手紙の内容と設定はすべて **deflate 圧縮 + Base64URL でリンクの `#` フラグメントに埋め込まれます**。
- サーバーには何も保存・送信されません。リンクを知っている人だけが手紙を開けます。
- 下書きはブラウザの localStorage に自動保存されます。

## 使い方 / 公開方法

静的ファイル1枚なので、そのまま配信できます。

- **GitHub Pages(推奨)**: このリポジトリには `.github/workflows/deploy-pages.yml` が含まれており、
  main ブランチへマージすると `letter/` フォルダだけが自動で GitHub Pages へデプロイされます
  (リポジトリ内の他のファイルは公開されません)。
  公開後は `https://<user>.github.io/<repo>/` でアクセスできます。
  (動かない場合は Settings → Pages → Source を「GitHub Actions」にしてください。無料プランでは公開リポジトリのみ)
- **Netlify / Vercel / Cloudflare Pages**: リポジトリを接続するだけで動きます。
- ローカルでも `letter/index.html` を開けば動作しますが、**共有リンクは公開ページ上で作成する必要があります**。
  PC内のファイルとして開いたまま作ったリンク(`file:///…`)は、そのPCでしか開けません。

※ フォントは Google Fonts から読み込むため、オンライン環境での閲覧を想定しています(読み込めない場合はシステムフォントで表示されます)。

## 画像クレジット

世界地図の背景 `world.jpg` は NASA の衛星合成画像(Blue Marble、パブリックドメイン)を元にしたものです。
